This repository houses the source code for my personal systems engineering and automation portfolio. ## 📂 Featured Projects

### 🔹 Sieve: Asynchronous Enterprise Document ETL Engine
An advanced, multi-entry polymorphic pipeline designed to handle unstructured, chaotic document data streams with absolute structural resilience. 
* Generates a programmatic SHA-256 cryptographic integrity hash to guarantee data idempotency and block document duplication vectors.
* Executes an asynchronous fan-out strategy, processing raw layout files through parallel tracks: building 3072-dimensional vector embeddings while simultaneously passing objects to an inline VLM for zero-shot taxonomy classification.
* Implements a confidence-gated routing system ($Threshold = 0.8$) that parses messy outputs via JavaScript regular expressions and dynamically enforces human-in-the-loop fallback overrides when model predictability dips.

### 🔹 CROSSCHECK SEARCH: State-Gated Telegram RAG Loop
A production-grade Retrieval-Augmented Generation (RAG) platform integrated into a custom Telegram client interface (`IMAGINIT_BOT`).
* Intercepts natural-language inputs, sanitizing syntax strings instantly using advanced JavaScript regex filters.
* Transforms prompts into mathematical vector arrays on the fly, invoking direct PostgreSQL Remote Procedure Calls (RPC) to perform cosine distance calculations against database records.
* Employs highly deterministic prompt boundaries inside `gemini-2.5-flash` to completely eliminate AI hallucinations, returning concise, context-bounded markdown payloads back to the end-user.

### 🔹 Universal File Converter Pipeline
A distributed data transformation tool pairing n8n automation nodes with custom text-based Python execution blocks to manipulate file data layouts that standard visual programming nodes cannot process natively.
